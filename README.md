# Simple Interest Calculator

This project is a simple interest calculator that computes the interest on a principal amount over a specified time period at a given rate of interest.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## How It Works
The calculator accepts three inputs:
- **Principal**: The initial amount of money
- **Rate of Interest**: The annual interest rate (in percentage)
- **Time Period**: The duration in years

## Example
If you invest $1,000 at 5% interest for 3 years:
- Simple Interest = (1000 × 5 × 3) / 100 = **$150**

## Usage
Run the `simple-interest.sh` script and enter the required values when prompted.
